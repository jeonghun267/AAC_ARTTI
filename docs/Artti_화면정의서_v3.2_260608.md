# **1. ****문서 개요**

## **1.1 ****문서 목적**

본 문서는 아르띠 앱의 화면 구성과 각 화면의 동작을 정의한다. 개발 담당자가 Unity Scene을 구현할 때 참조할 수 있도록 화면 단위로 진입 경로, 구성 요소, 사용자 액션, 다음 화면 전환을 명시한다. 본 문서의 모든 결정은 PLAN.md를 기반으로 하며, 충돌이 발생할 경우 PLAN.md를 정답으로 본다.

## **1.2 ****적용 범위**

본 문서는 Scene 전환 레벨까지의 화면을 정의한다. 다음 범위는 별도 문서로 분리한다.

· 훈련모드 시나리오 내부 turn 흐름: 카드 팝업, STT, LLM 대화 매니저, NPC 응답까지의 단일 turn 처리 (PLAN.md 5.2절 참조)

· AR현장모드 내부 Panel 전환: 카메라 Panel, 인식 결과 확인 Panel, 대분류 Panel, 소분류 Panel (PLAN.md 5.3절 참조)

## **1.3 1****차 폼팩터 정책**

· 1차 폼팩터는 태블릿 가로(landscape) 모드로 통일한다.

· AR현장모드도 가로 모드로 통일하여 일관된 사용 경험을 제공한다. AR Foundation의 ARCameraBackground가 가로 카메라 영상을 자동 출력한다.

· 훈련모드의 AAC 카드 그리드는 메인 2장 + 기타 1장의 2+1 그리드 배치를 채택한다 (PLAN.md 5.2.2절).

· AR현장모드의 AAC 카드 그리드는 최대 4장을 2×2 그리드로 배치한다 (PLAN.md 5.3절).

## **1.4 ****디자인 토큰**

| **Primary Color** | #1A56DB (코발트 블루) — 주 CTA, 선택 강조, 기본 강조 |
| --- | --- |
| **Accent Color** | #F97316 (주황) — 포인트, 중요 알림, 진행 표시 |
| **선정 근거** | 색각 이상(특히 적록색각이상) 사용자의 변별성을 우선 고려. 파랑-주황은 적록·청황 양쪽 색각 이상에서 모두 잘 구분되는 대표 페어 |
| **색 접근성 원칙** | 색만으로 정보를 전달하지 않는다. 선택 상태는 색 + 두꺼운 테두리 + 체크 아이콘. 오류는 색 + 아이콘 + 텍스트 |
| **선택 강조 패턴** | 큰 카드 = 두꺼운 테두리 + 좌상단 체크 아이콘 (빛/배경 강조 미사용). 작은 아이콘 = 테두리 강조 |
| **최소 터치 영역** | 72dp 이상 (PLAN.md 7.2.8절) |

## **1.5 ****사용자 식별 정책**

· 1차 MVP는 구글/네이버/카카오 등 외부 계정 로그인을 도입하지 않는다. 로컬 다중 프로필 방식을 유지한다 (PLAN.md 8.2절 B안).

· 한 기기를 여러 이용자가 돌려 쓰는 환경(특수학교 태블릿 공용 사용, 복지관 등)을 핵심 시나리오로 한다.

· 교사·보호자·복지사 전용 모드는 별도로 두지 않는다. 학습 기록 확인은 레포트 메뉴를 통해 수행한다.

· 프로필 생성 시 필수 입력은 대표 이미지와 색상이며, 이름은 선택 입력이다. 생년월일·연락처 등 개인 특정 정보는 수집하지 않는다 (PLAN.md 8.5절).

화면 ID는 SC- 접두사 뒤에 화면 그룹과 두 자리 번호로 구성한다. 그룹은 다음과 같다.

| **SC-01x** | 공통 진입 화면 (Splash, 타이틀, 설정) |
| --- | --- |
| **SC-02x** | 프로필 관련 화면 (선택, 생성, 수정) |
| **SC-03x** | 메인 화면 (MainScene) |
| **SC-04x** | 음성언어모드 = 훈련모드 (TrainingHubScene, 시나리오 Scene) |
| **SC-05x** | 시각언어모드 = AR현장모드 (ARFieldScene) |
| **SC-06x** | 레포트 화면 |

## **3.3 ****채택****·****제외된 레퍼런스 요소 요약**

본 화면정의서는 제니코그AI와 토도한글 두 레퍼런스의 검토 결과를 반영한다. 채택된 요소는 다음과 같다.

· 제니코그: 시나리오 카드 안 메타정보 패턴, 4-카드 정량 그리드 + 캘린더 위젯 + 격려 문구 (레포트 화면), 타이틀 우상단 설정 진입

· 토도한글: 아바타 시각 중심 + 텍스트 보조 패턴, 선택 상태 강조 (큰 카드 = 테두리, 작은 아이콘 = 테두리), 타이틀 → 사용자 선택 → 정보 입력의 진입 흐름, 대표 이미지 그리드 + 색상 선택

제외된 요소는 다음과 같다.

· 제니코그: 정답/오답 확인 버튼, 문제수/정답률 지표, AI 추천 슬라이더, 세션 카운트다운 타이머, 상위 모드 탭 통합, “순서대로 시작하기” 단일 CTA

· 토도한글: 부모님 전용 메뉴, 시작 화면 게임적 비주얼, 생년월일/이중 언어 입력, 드롭다운 위젯, 프로필별 정보 보기 별도 버튼 (단, 본 프로젝트는 “레포트 확인”으로 재해석하여 채택)
